📚 操作指南（八股与 Coding 导入的说明 + 推荐题源）

① AI 出题（下方）：粘贴一道题的描述，或只写出题要求（如"出一道单调栈中等题"）。AI 生成题面与参考解后，系统在本地沙箱实跑参考解生成全部期望输出——期望输出永远来自真实运行，不来自 AI 猜测；参考解跑挂会自动喂回 AI 修复。

② AI 适配导入：把题目描述保存为 .md / .txt（一题一文件）放进一个目录，指向该目录即可批量导入。每道题都会走"AI 生成参考解+用例 → 沙箱验证自洽"流程，任何来源的题面文本都能变成可判题的题。

③ JSON 直接导入：已有结构化题目（含测试用例）可按 seeds/coding/cp-001.json 的格式（字段：id / title / difficulty / tags / statement / test_cases[{input, output}]）放入目录直接导入，不消耗 AI。

推荐题源（本仓库不分发任何题目内容，请自行下载到本地）：

  • doocs/leetcode（MIT，74k+ star）：多语言题解与题面，可整库 clone 后挑选若干题保存为 md 导入
  • OI-wiki（CC BY-SA 4.0）：算法知识库，更适合作为八股知识导入
  • 自己的刷题笔记 / 任何文本形式的题目描述

八股导入指南：支持 PDF（需文字层，扫描图自动跳过）/ Markdown / TXT，递归扫描子目录；按文件内容哈希增量去重，重复导入只处理新文件。成本参考：92 个 PDF（51 万字）≈ 100 万 token ≈ 几元。首次建议先限制 2-3 个文件试跑。
